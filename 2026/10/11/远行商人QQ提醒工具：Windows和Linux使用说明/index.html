远行商人QQ提醒工具：Windows和Linux使用说明
发表于：2026-10-11 | 分类： 技术
字数统计: 2k | 阅读时长: 7分钟 | 阅读量：

开端

上一篇 记录一下洛克王国世界远行商人爬虫的制作过程 写了这个小工具是怎么做出来的，这次顺手把文件整理了一下，放到 GitHub 上，方便有需要的人直接使用。

Windows 版做了一个配置窗口，Linux 版提供命令行和后台定时任务。两个打包版本都不需要另外安装 Python。

使用的时候登录自己的 QQ，填写自己的接收账号即可。

下面记录一下安装方法。

下载

GitHub 下载页：远行商人 QQ 提醒 v1.0.1

文件 适用情况
Windows 版 Windows 10/11 64位，有配置窗口
Linux 版 Linux x86_64，命令行使用
源码包 自己修改或用 Python 运行
SHA256 校验文件 核对下载文件

Linux 可执行文件在 Ubuntu 22.04 上构建，需要 x86_64 架构和 glibc 2.35 或以上。Ubuntu 22.04/24.04 可以作为使用环境；ARM、Alpine 或较老的系统可以考虑源码方式，不要直接套用这个二进制包。

源码也可以直接在 GitHub 项目目录 查看，使用 MIT 许可。

下载后先完整解压，不要在压缩包里面直接运行。 程序需要在自己的文件夹里保存配置和推送记录。

先准备 QQ 推送

1.安装 NapCat，登录自己的 QQ

这个工具负责查商品，QQ 登录和消息发送由 NapCat 完成。

先按 NapCat 官方安装说明 下载对应系统的版本，启动以后，按提示完成 QQ 登录或扫码验证。

建议用一个机器人 QQ 给自己的主 QQ 发消息，先加好好友。要发到 QQ 群，则让机器人加入目标群。

包里没有我的 QQ 登录状态、访问令牌或者接收名单，第一次使用需要自己配置。

Windows 使用方法

1.打开程序

解压 Windows 包后，双击 RockMerchantQQ.exe。

配置窗口如下：

如果还没启动 NapCat，可以通过窗口里的说明链接安装，或者点击“打开 NapCat 登录自己的 QQ”，选择 NapCat 安装目录里的启动文件。

扫码和密码验证仍然在 NapCat 中完成。

2.填写配置并测试

依次填写：

  1. HTTP 接口地址。
  2. 刚刚设置的 HTTP Token。
  3. 接收方式：QQ 私聊或 QQ 群。
  4. 接收 QQ 号或群号，多个号码用逗号分隔。

先点击 “检查 QQ 登录”，确认显示的是自己登录的机器人账号。

然后点击 “发送测试”，接收端应该收到一条中文测试消息。只有通道正常了，再去看商品是否更新，比较方便排查问题。

“预览商品”只显示当前轮次的商品，不会给 QQ 发消息。

3.开启自动提醒

点击 “开启自动提醒”。程序会为当前文件夹创建一个定时任务，约一分钟后首次检查，之后每五分钟检查一次。

设置好以后可以关闭配置窗口，检查任务会在后台运行。NapCat 需要保持在线，Windows 用户也需要保持登录。 电脑关机或休眠期间不会查询。

以后不需要了，重新打开程序，点击“关闭自动提醒”即可，配置和历史记录会保留。

NapCat 的开机启动要按它自己的安装方式设置。本工具不会替你完成重启后的扫码登录。移动程序文件夹时，也要先关闭旧任务，移动后再重新开启。

一些说明

1.什么时候会发消息

商品轮次按北京时间计算，分别是 08:00、12:00、16:00、20:00。凌晨 00:00-08:00 不发送商品提醒。

每五分钟检查一次，不代表每五分钟都发一条。没有新内容时会跳过；如果源站还没更新，也不会强行发一份空列表。

★ 标注的是根据源站和本地规则判断的稀有或高价值商品，可以在配置文件里修改名单。

2.低负载和订阅

低负载模式默认开启：同一天同一轮成功发送后，就不再重复抓商品。

代价是不会继续检查这一轮后续的修正。希望持续检查的话，可以在 Windows 窗口取消勾选，Linux 则把 config.json 中的 monitor.low_power_mode 改成 false。

好友自助订阅默认关闭，且只适用于私聊推送。开启以后，好友私聊机器人发送“开启推送”，会在下一次检查时加入名单。

3.文件保存在哪里

配置、推送记录和日志都放在程序旁边：

分享给别人时，直接分享上面的原始下载包即可。自己运行后生成的配置和 NapCat 登录目录就不要一起打包了。

4.收不到消息先检查什么

先点“检查 QQ 登录”，再发一条测试消息。

如果登录检查失败，先检查 NapCat 是否在线、HTTP 服务是否开启，以及地址、端口和 Token 有没有填错。

如果测试消息正常，但没有商品提醒，就检查北京时间、源站更新情况和日志。刚改完接收名单时，本轮推送记录也不会自动清空，可以先用测试消息确认，新一轮再正常接收。

后记

这次把原来只适合自己电脑的文件整理成了公开版本，去掉固定账号和本机路径，也补上了配置入口、两个系统的打包和使用说明。

Windows 和 Linux 分别构建，打包后也会运行自检。源码和下载文件都放在 GitHub，后面有需要再继续调整。

详细说明也放在压缩包里的 README.md，下载后可以随时查看。

自己用自己的 QQ 收提醒，省得每天再去翻商品列表了。
